Archivo CSV

El archivo CSV debe tener el siguiente formato:


    id,calificador_id,evaluado_id,fecha_entrevista
    F9999999-PEREZ LOPEZ,20080373,F9999999,2026-09-11T17:00:00
    F9999998-RUIZ RAMOS,20080373,F9999998,2026-09-12T15:30:00
    F9999997-CAMPOS SAENZ,99999999,F9999997,2026-09-11T17:00:00

Todos los campos son obligatorios, revisar que no haya id duplicados, si el id ya existe, la carga fallará

Descripción de las columnas:

  1. id : Un identificador único de la ficha, usualmente se pone CODIGO-APELLIDOS como en el ejemplo
  2. calificador_id : El id del calificador (usualmente su código PUCP)
  3. evaluado_id : El id del evaluado (usualmente su código de postulante)
  4. fecha_entrevista : La fecha de la entrevista, debe tener el siguiente formato: yyyy-mm-ddThh:mm:ss
