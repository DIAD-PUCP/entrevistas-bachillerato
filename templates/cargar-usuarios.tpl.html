Cargar usuarios

Archivo CSV

El archivo CSV debe tener el siguiente formato:


    id,apellido_paterno,apellido_materno,nombres,email,password,activo
    20080373,MORENO,VALLES,FERNANDO ANTONIO,fernando.moreno@pucp.edu.pe,Diad2025#,True
    99999999,INOQUIO,SENADOR,MARCO,minoquio@pucp.edu.pe,8rStDs283,True

Todos los campos son obligatorios, revisar que no haya id duplicados, si el id ya existe, la carga fallará. Todos los usuarios se crean con perfil Calificador

Descripción de las columnas:

  1. id : Un identificador único del usuario, usualmente el código PUCP
  2. apellido_paterno : El apellido paterno del usuario
  3. apellido_materno : El apellido materno del usuario, de no tener usar un guión o un espacio en blanco
  4. nombres : Los nombres del usuario
  5. email : El correo del usuario, no necesariamente tiene qe ser PUCP, este se usará para el login
  6. password : El password del usuario, usar los indicados en la hoja de cálculo de los entrevistadores
  7. activo : "True" para crear el usuario activo o "False" para crearlo desactivado
